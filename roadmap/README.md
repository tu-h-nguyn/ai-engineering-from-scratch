# AI Engineering Learning System

This directory is the structured curriculum layer for the repository.

The curriculum is organized as a dependency graph rather than a flat checklist:

**Foundation → ML → Deep Learning → Specialized AI → Transformers → LLM → AI Engineering → Agents → Production → Capstone**

Each phase is viewed through four complementary lanes:

1. Theory — concepts, mathematics, papers.
2. Implementation — algorithms and models from scratch and with frameworks.
3. Engineering — data, experiments, testing, APIs, deployment, reliability.
4. Project — an artifact that demonstrates the phase in practice.

The machine-readable source of truth is `roadmap.json`. The visual roadmap lives in `../dashboard/`.

A topic is considered evidence-backed when it has understanding, implementation, experiment/evaluation, and an artifact or project where appropriate.
